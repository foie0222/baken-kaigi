# レースダッシュボード設計

## 概要

1画面で特定レースの全情報を閲覧しつつ馬券購入できるPC全画面ダッシュボードへの方針転換。

## レイアウト

```
+------------------------------------------------------------------+
| ヘッダー: 馬券会議 | レースセレクタ | ユーザー              |
+------------------------------------------------------------------+
| メインテーブル (70-75%)             | 馬券パネル (25-30%)    |
| +----------------------------------+ +----------------------+ |
| | 枠|馬番|馬名|騎手|体重|          | | 券種選択              | |
| |   AI予想(5サイト)|SP指数(3サイト)| | 馬選択状態            | |
| |   単勝オッズ|人気                 | | 買い方                | |
| |                                  | | 金額入力              | |
| | [展開行: 過去成績/調教/血統]      | | カート                | |
| +----------------------------------+ | 購入ボタン            | |
|                                      +----------------------+ |
+------------------------------------------------------------------+
```

## カラースキーム（ダークテーマ）

- 背景: `#0a0a0f`
- サーフェス: `#1a1a2e`
- プライマリ: `#e94560`
- テキスト: `#eee`
- テキスト(muted): `#888`
- 成功: `#4ade80`
- 警告: `#f59e0b`

## データソース

- 出馬表: `/races/{raceId}` (既存)
- オッズ: `/races/{raceId}/odds` (既存)
- AI予想: `/races/{raceId}/ai-predictions` (新規)
- スピード指数: `/races/{raceId}/speed-indices` (新規)

## 実装範囲

1. CSS変数をダークテーマに変更、max-width制限を撤廃
2. 新ページ `RaceDashboardPage` 作成
3. バックエンドにAI予想/スピード指数APIエンドポイント追加
4. APIクライアントにメソッド追加
